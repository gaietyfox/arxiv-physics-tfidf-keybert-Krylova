# arXiv Physics Text Analysis: TF-IDF and KeyBERT

Проект посвящён автоматизированному сбору и анализу полнотекстовых научных публикаций из открытого архива arXiv с использованием методов TF-IDF и KeyBERT.

Первоначально методика была разработана и протестирована на публикациях категории Quantum Physics (`quant-ph`). Затем был создан универсальный Python pipeline, позволяющий применять ту же процедуру к различным категориям физики arXiv.

## Цель проекта

Цель работы - сформировать корпус научных публикаций, выделить характерные термины и словосочетания двумя методами и определить термины, обнаруживаемые одновременно TF-IDF и KeyBERT.

Разработанный pipeline автоматизирует следующие этапы:

1. получение метаданных публикаций arXiv
2. формирование корпуса новых и более ранних публикаций
3. получение полных текстов
4. предварительную обработку текста
5. анализ TF-IDF
6. извлечение ключевых терминов с помощью KeyBERT
7. сопоставление результатов двух методов
8. сохранение корпуса и результатов в JSON
9. автоматическую проверку структуры выходных файлов


### `results/`

Содержит итоговые результаты работы pipeline в формате JSON для протестированных категорий:

- `quant-ph`
- `astro-ph`
- `physics.ao-ph`

## Формирование корпуса

Для каждой анализируемой категории формируется корпус из 100 публикаций:

- 50 новых публикаций за выбранный месяц
- 50 публикаций за предыдущие 24 месяца

Публикации предыдущего периода распределяются по двухлетнему интервалу для представления разных временных точек.

Для воспроизводимости случайной выборки используется:

```python
random_seed = 42
```

## Получение полных текстов

Для выбранных публикаций pipeline автоматически получает полные тексты с arXiv.

В первую очередь используется HTML-версия публикации. Если получить достаточный объём текста из HTML невозможно, используется PDF и извлекается его текстовый слой.

OCR не используется.

Для каждой публикации сохраняется информация об источнике текста (`html` или `pdf`).

## Предварительная обработка

Перед анализом выполняется предварительная обработка текста, включающая нормализацию регистра, удаление отдельных технических элементов и нормализацию пробелов.

При этом исходный полный текст сохраняется отдельно от версии, используемой для анализа.

## TF-IDF

TF-IDF используется для поиска терминов и словосочетаний, наиболее характерных для конкретной новой публикации относительно публикаций предыдущего периода.

Для каждой из 50 новых публикаций анализ выполняется отдельно:

```text
50 публикаций предыдущего периода
+
1 новая публикация
```

Используется `TfidfVectorizer` из `scikit-learn`:

```python
TfidfVectorizer(
    stop_words="english",
    ngram_range=(1, 3),
    min_df=1,
    max_df=0.95,
)
```

Таким образом, анализируются униграммы, биграммы и триграммы.

В универсальном pipeline используется порог:

```text
TF-IDF > 0.1
```

В исследовательском notebook дополнительно рассматривается чувствительность результатов к различным пороговым значениям TF-IDF.

## KeyBERT

KeyBERT применяется отдельно к каждой новой публикации.

В итоговой конфигурации используются следующие параметры:

```text
KeyBERT score > 0.4
top_n = 2000
ngram range = 1-3
```

`top_n` задаёт максимальное количество кандидатов, возвращаемых KeyBERT.

Pipeline также выполняет диагностическую проверку, позволяющую определить публикации, для которых установленное значение `top_n` потенциально может ограничивать количество терминов, удовлетворяющих заданному порогу.

## Сопоставление методов

После выполнения TF-IDF и KeyBERT полученные термины нормализуются и сопоставляются внутри одной и той же публикации.

Совпадением считается точное совпадение нормализованного термина, выделенного обоими методами.

## Выходные JSON-файлы

Pipeline формирует два типа файлов для каждой категории.

### `*_corpus.json`

Содержит полный корпус из 100 публикаций.

Для каждой публикации сохраняются:

```text
arxiv_id
title
subjects
category
month
period
text_source
full_text
analysis_text
```

Таким образом, файлы корпуса включают метаданные, полные тексты публикаций и предобработанные тексты.

### `*_results.json`

Содержит параметры и результаты анализа.

Основная структура:

```text
metadata
parameters
summary
articles
```

В JSON сохраняются параметры TF-IDF и KeyBERT, сводные показатели и результаты анализа каждой новой публикации, включая:

- термины TF-IDF и их значения
- термины KeyBERT и их значения
- пересечение результатов двух методов

## Доступность корпусов

Полные файлы `*_corpus.json` не включены в данный GitHub-репозиторий из-за их большого размера, превышающего ограничение загрузки файлов через веб-интерфейс GitHub.

Это связано с тем, что каждый файл корпуса содержит полные тексты 100 научных публикаций.

Корпуса формируются и сохраняются автоматически при запуске pipeline. Поэтому их можно воспроизвести непосредственно из исходных данных arXiv с помощью `arxiv_physics_pipeline_Krylova.ipynb`.

Итоговые `*_results.json` включены в папку `results/`.

## Проверка данных

После завершения анализа pipeline автоматически проверяет:

- количество публикаций в сформированном корпусе
- наличие обязательных полей
- наличие полных текстов
- структуру итогового JSON с результатами
- количество проанализированных новых публикаций

## Пример запуска

Для запуска pipeline необходимо указать категорию arXiv, анализируемый месяц и основные параметры:

```python
results = run_pipeline(
    category="quant-ph",
    recent_year=2026,
    recent_month=7,
    n_per_group=50,
    tfidf_threshold=0.1,
    keybert_threshold=0.4,
    keybert_top_n=2000,
    reuse_saved_corpus=True,
)
```

Если соответствующий корпус уже существует локально:

```python
reuse_saved_corpus=True
```

позволяет использовать сохранённые данные повторно.

Для формирования нового корпуса используется:

```python
reuse_saved_corpus=False
```

## Проверенные категории

Универсальный pipeline был протестирован на следующих категориях arXiv:

- `quant-ph` - Quantum Physics
- `astro-ph` - Astrophysics
- `physics.ao-ph` - Atmospheric and Oceanic Physics

Для перехода к другой категории основная логика анализа не изменяется.

## Ограничения

Сопоставление результатов TF-IDF и KeyBERT основано на точном совпадении нормализованных терминов. Поэтому семантически близкие, но различно сформулированные выражения автоматически не считаются совпадениями.

Качество текста, извлечённого из PDF, зависит от структуры исходного документа. OCR в pipeline не используется.

Для крупных категорий количество публикаций на месячной странице arXiv может достигать установленного лимита получения данных. В таком случае pipeline выводит предупреждение.

Значения TF-IDF и KeyBERT относятся к различным методам и не рассматриваются как непосредственно сопоставимые шкалы.
